# Bank Account Management System

A robust Java-based application designed to manage bank accounts, handle customer transactions, and maintain secure financial records. This project includes comprehensive unit tests and software requirement documentation.

---

## 🚀 Features
- **Account Operations:** Create accounts, deposit funds, withdraw funds, and check balances.
- **Transaction Management:** Track account history and securely process monetary movements.
- **Automated Testing:** Integrated JUnit tests ensuring code reliability and logic validation.
